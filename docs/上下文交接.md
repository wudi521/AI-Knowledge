## 7. 前端弹窗规范(必读,用户明确要求)

**凡弹窗打开新弹窗(嵌套弹窗),每层都必须配置"关闭即摧毁",且显式设置 z-index 分层:**

1. **vben 弹窗**(`useVbenModal`)→ 必须 `destroyOnClose: true`
   ```ts
   const [EditModal, editModalApi] = useVbenModal({
     connectedComponent: EditForm,
     destroyOnClose: true,
     zIndex: 2000,   // 嵌套时显式高于外层 antd Modal(1000)
   });
   ```
2. **antd 弹窗**(`<Modal>`)→ 必须 `:destroy-on-close="true"` + 显式 `:z-index="1000"`
   ```vue
   <Modal v-model:open="..." :footer="null" :z-index="1000" :destroy-on-close="true">
   ```
3. **层级原则**:antd Modal 统一 `z-index: 1000`,vben 子弹窗统一 `z-index: 2000`——嵌套时子弹窗必在前
4. **已遵循此规范**:`views/ai/document/chunk-modal.vue`、`views/ai/chunk/index.vue`
5. 弹窗关闭后在 `onOpenChange(isOpen=false)` 里重置状态(避免数据残留)

## 8. 前端展示规范(本次踩坑总结)

1. **时间列**:一律加 `formatter: 'formatDateTime'`(vxe 惯例),显示 yyyy-MM-dd HH:mm:ss
2. **主题色**:不要硬编码 `text-gray-600`/`bg-gray-50`/`text-gray-400`(夜间模式看不清),用 `text-muted-foreground`/`bg-muted`/`text-card-foreground` 等主题感知类
3. **操作列宽度**:3 个按钮(查看/编辑/删除)需 ≥220px,2 个按钮 ≥180px,否则右侧按钮被遮挡(本次删除按钮被 150px/90px 列宽遮住)
4. **删除确认**:用 TableAction 的 `popConfirm`(antd Popconfirm,vxe 标准),不要用 vben 的 `confirm`(可能不弹)
5. **中文映射**:切分策略 Semantic→语义切分/ParentChild→父子切分/Table→表格切分/FAQ→问答切分/Policy→条款切分(CHUNK_STRATEGY_TEXT)
6. **下载文档**:`window.open(row.storagePath, '_blank')`(MinIO 未鉴权直链)
7. **checkbox 事件**:useVbenVxeGrid 的 Grid 不支持模板 `@checkbox-change`,要用 `gridEvents: { checkboxChange, checkboxAll }` 配置;取选中行用 `gridApi.grid.getCheckboxRecords()`
