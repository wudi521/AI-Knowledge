## 6. 技术要点速查

- **芋道 Feign 规范**:接口 @FeignClient + @GetMapping/@PostMapping(PREFIX+路径)+ CommonResult<T>;实现类必须 **@RestController**(不是 @Service);占位方法必须 @FeignIgnore
- **Kafka 序列化**:JsonSerializer/JsonDeserializer + spring.json.trusted.packages:"*"(knowledge 和 ingestion 的 yaml 都配了)
- **Milvus**:集合 ai_chunk_vector(1024维,chunk_id PK,tenant_id/kb_id 标量),insert 前 ensureCollection 自愈
- **ES**:索引 ai_chunk_bm25(chunk_id/tenant_id/kb_id/status keyword + content text),无 ik;_bulk 删除用 application/x-ndjson
- **入库幂等**:deleteByVersionId + @Transactional + FAILED 后重抛异常触发回滚;chunk 落库在事务内,**notifyParsed 必须事务提交后(afterCommit)再调**(否则 knowledge 回读不到 chunk → 空抽取 → 误自动发布)
- **删除三处联动**:ES deleteChunks(批量 _bulk)→ Milvus deleteVectors(expr in)→ MySQL deleteBatchIds/deleteByVersionId(最后删);删文档级联:片段三处 → 审核条目/冲突(按版本)→ 版本 → 文档行
- **前端菜单**:system_menu 表;知识治理菜单 6753 知识审核/6754 版本管理/6755 冲突裁决 + 权限行 6756-6761;AI 菜单父节点 2758
- **前端联表字段**:文档分页返回 kbName/chunkStrategy/embedModel + versionNo/versionStatus;片段分页返回 documentName/storagePath + versionNo(version_id 已是真实版本 id,需经 versionMap 联表)
- **知识治理关键接口**:`notifyParsed(documentId, versionId)`(ingestion 事务提交后调)、`indexVersion(versionId, kbId, tenantId)`(幂等覆盖式,置 PUBLISHED 最后一步)、`getChunksByVersion`/`getVersionMap`/`getDocVersionIds`(片段页/级联删除联表)
- **chat 模型**:LM Studio `qwen/qwen3-8b`(yudao.model.chat.* 配置);embedding 仍用 text-embedding-bge-m3
- **⚠️ qwen3 思考模式(2026-08-17 踩坑)**:qwen3 默认开 thinking,CPU 推理会 0 输出+极慢(59s/0字);ModelApiImpl.chat 已显式 `chat_template_kwargs.enable_thinking=false` + `thinking.type=disabled` + `max_tokens=1024`;抽取批次 5、knowledge→model Feign 读超时 5 分钟;抽取超时/失败后文档置 FAILED,文档页「重试抽取」可恢复(afterCommit 通知失败只记日志不抛,防 Kafka 重试重复插 chunk)

## 7. 前端弹窗规范(必读,用户明确要求)

**凡弹窗打开新弹窗(嵌套弹窗),每层都必须配置"关闭即摧毁",且显式设置 z-index 分层:**

1. **vben 弹窗**(`useVbenModal`)→ 必须 `destroyOnClose: true`
   ```ts
   const [EditModal, editModalApi] = useVbenModal({
     connectedComponent: EditForm,
     destroyOnClose: true,
     zIndex: 2000,   // 嵌套时显式高于外层 antd Modal(1000)
   });
   ```
2. **antd 弹窗**(`<Modal>`)→ 必须 `:destroy-on-close="true"` + 显式 `:z-index="1000"`
   ```vue
   <Modal v-model:open="..." :footer="null" :z-index="1000" :destroy-on-close="true">
   ```
3. **层级原则**:antd Modal 统一 `z-index: 1000`,vben 子弹窗统一 `z-index: 2000`——嵌套时子弹窗必在前
4. **已遵循此规范**:`views/ai/document/chunk-modal.vue`、`views/ai/chunk/index.vue`
5. 弹窗关闭后在 `onOpenChange(isOpen=false)` 里重置状态(避免数据残留)

## 8. 前端展示规范(本次踩坑总结)

1. **时间列**:一律加 `formatter: 'formatDateTime'`(vxe 惯例),显示 yyyy-MM-dd HH:mm:ss
2. **主题色**:不要硬编码 `text-gray-600`/`bg-gray-50`/`text-gray-400`(夜间模式看不清),用 `text-muted-foreground`/`bg-muted`/`text-card-foreground` 等主题感知类
3. **操作列宽度**:3 个按钮(查看/编辑/删除)需 ≥220px,2 个按钮 ≥180px,否则右侧按钮被遮挡(本次删除按钮被 150px/90px 列宽遮住)
4. **删除确认**:用 TableAction 的 `popConfirm`(antd Popconfirm,vxe 标准),不要用 vben 的 `confirm`(可能不弹)
5. **中文映射**:切分策略 Semantic→语义切分/ParentChild→父子切分/Table→表格切分/FAQ→问答切分/Policy→条款切分(CHUNK_STRATEGY_TEXT)
6. **下载文档**:`window.open(row.storagePath, '_blank')`(MinIO 未鉴权直链)
7. **checkbox 事件**:useVbenVxeGrid 的 Grid 不支持模板 `@checkbox-change`,要用 `gridEvents: { checkboxChange, checkboxAll }` 配置;取选中行用 `gridApi.grid.getCheckboxRecords()`
