# 多轮对答与上下文实施计划(6 任务)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** 生产级多轮对答: 历史结构化传递(chat→evidence→retrieval 消歧 + 生成带历史)、上下文截断与 token 控制、history 快照落库、会话摘要, 端到端可验证。

**Spec:** `docs/superpowers/specs/2026-08-18-多轮上下文-design.md`

---

## 环境前提
- chat-server(48083)/evidence-server(48087)/retrieval-server(48086)/model-server(48091) 已交付单轮链路
- ai_message 已落库(历史来源);ai_conversation 有 summary/transfer_reason/operator_id
- yaml 已有 `yudao.chat.max-context-messages: 6`(未生效, 需绑定)

## 任务

### Task 1: DTO 链路 + 透传 + history 快照落库
- evidence-api: `ChatTurnDTO{role, content}`;EvidenceEvaluateReqDTO 加 `List<ChatTurnDTO> history`;EvidenceEvaluateRespDTO 加 `List<ChatTurnDTO> history`(回显)
- retrieval-api: 自身 `ChatTurnDTO`(同构);RetrievalSearchReqDTO 加 `List<ChatTurnDTO> history`
- evidence-server: EvidenceService.evaluate 加 history 参数(重载, 旧签名委托);EvidenceAssembler.assemble 加 history → RetrievalSearchReqDTO.setHistory;EvidenceApiImpl 映射 history
- evidence-server: EvidenceService 落库 ai_evidence_eval 时 history 快照(JSONUtil.toJsonStr);EvidenceEvalDO 加 history 字段 + DDL `ALTER TABLE ai_evidence_eval ADD COLUMN history json NULL COMMENT '评估上下文快照'`
- retrieval-server: SearchService.search 加 history 重载(旧签名保留);透传给 QueryAnalysis
- 编译 + 启动冒烟(单轮兼容: history=null 行为不变)

### Task 2: QueryAnalysis 消歧
- QueryAnalysis.analyze(query, history): user prompt 结构化为"历史对话区 + 当前问题";system 要求 rewrites 结合历史展开指代、products/entities 继承
- 结构化兜底: LLM 失败且历史非空 → 当前问题 + 最近 USER 消息拼接为 rewrite
- 验证: "那换屏多少钱" + 历史"X100 Pro 碎屏能免费修吗" → rewrites 含"X100 Pro 换屏 多少钱"/products=[X100 Pro]

### Task 3: 生成带历史
- AnswerGenerator.generate(query, evidences, history): prompt 附历史(截断后, 每条≤200字总≤2000字, "仅供指代理解, 不要复述")
- ClaimVerifier.verify(query, answer, evidences, history): 同上
- AnswerPipeline.generateWithClaims(query, evidences, history) 透传
- 编译验证

### Task 4: ChatPipeline 上下文 + 配置绑定 + 计数
- MessageService.getRecentMessages(conversationId, limit): 取最近 N 条 USER/AI(排除 SYSTEM), create_time asc
- ChatPipeline: 读历史 → 截断(轮数/条长/总长)→ 构造 List<ChatTurnDTO> → evaluate(..., history)
- `yudao.chat.max-context-messages` 绑定(@ConfigurationProperties ChatProperties 或并入 TransferProperties 改名 ChatProperties;核对 yaml 键)
- ConversationService: messageCount 计数(DDL `ADD COLUMN message_count int NOT NULL DEFAULT 0`;addMessage 后自增)——简化: 查询 COUNT 也可, 决策选 count 字段增量更新
- 编译验证

### Task 5: TransferHandler 摘要增强 + context_summary
- buildSummary 附"近轮对话要点": 从历史取最近 3 条 USER+AI 规则拼接(不调 LLM)
- ai_conversation 加 `context_summary varchar(1000)`;manualTransfer/handleTransfer 时写入
- 编译验证

### Task 6: 端到端验证 MC-01~MC-06
- MC-01 多轮追问: 轮1"X100 Pro 碎屏能免费修吗" → 轮2"那换屏多少钱?" → 答 ¥699
- MC-02 history 快照落库可查(evidence_eval.history 含轮1)
- MC-03 SYSTEM 消息不进上下文
- MC-04 超长会话截断生效不报错
- MC-05 单轮兼容(无 history 行为不变)
- MC-06 context_summary 落库
- 前端对话工作台多轮体验(消息流已有, 无需改;确认)
