# 模型DB化 + 切分策略改造 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成模型配置全量数据库化(去 yaml 兜底)、切分策略文档级+插件化+结构化解析+图片识别(含 MinerU/视觉模型 Docker 部署)、意图/槽位业务评估文档。

**Architecture:** 子项目 A 改造 model-server 网关与成本服务, 模型连接/单价全部读 `ai_model_config` 表; 子项目 B 将入库管线从"纯文本→正则切分"升级为"结构化解析(MinerU/POI/视觉模型)→ParsedDocument 结构树→插件化切分(@ChunkStrategy 自动注册)→上下文增强(标题链/图片绑定)"。设计依据: `docs/superpowers/specs/2026-08-21-模型DB化与切分策略改造-design.md`。

**Tech Stack:** Java 17 / Spring Boot 3.5 / MyBatis-Plus / Apache POI / PDFBox / MinerU(独立服务) / Docker Compose
