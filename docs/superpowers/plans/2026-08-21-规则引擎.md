# 规则引擎 M7-A 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** yudao-module-rule(48088) 落地 Drools 规则引擎: DRL 存 DB(租户级版本化/灰度/回滚)、运行期编译执行、evidence 规则优先短路(命中硬规则直接给结论不走 LLM)、命中留痕。

**Architecture:** rule-server: ai_rule(租户级, status 0/1/2 同 prompt)+ ai_rule_hit 留痕 + RuleCompiler(保存试编译)+ RuleEngine(evaluate(ruleKey,tenantId,facts)→ List<RuleResult>, KieBase 30s 缓存)+ RuleApi.evaluate RPC + /rule/* 管理 API(含 validate 试运行)。evidence-server: RuleShortCircuit(组装问题事实→RPC→命中短路)。事实=Map, 结论=通用 RuleResult, 领域无关。

**Spec:** `docs/superpowers/specs/2026-08-21-规则引擎-design.md`

**Step 2: DDL** — `sql/migrate-20260821-ai-rule.sql`(镜像 ai_prompt 结构 + tenant):
```sql
CREATE TABLE IF NOT EXISTS `ai_rule` (
  `id` bigint NOT NULL AUTO_INCREMENT,
  `rule_key` varchar(64) NOT NULL COMMENT '业务键(如 warranty-condition/delivery-condition)',
  `name` varchar(128) NOT NULL,
  `description` varchar(500) NULL,
  `drl_content` text NOT NULL,
  `version` int NOT NULL DEFAULT 1,
  `status` tinyint NOT NULL DEFAULT 0 COMMENT '0停用/1启用全量/2灰度中',
  `gray_tenant_ids` varchar(500) NULL,
  audit 字段(creator/create_time/updater/update_time/deleted) + `tenant_id` bigint NOT NULL DEFAULT 0,
  PRIMARY KEY(id), INDEX idx_key_status(rule_key, status)
) ENGINE=InnoDB ... COMMENT='AI 硬规则(Drools DRL)';

CREATE TABLE IF NOT EXISTS `ai_rule_hit` (
  `id` bigint NOT NULL AUTO_INCREMENT,
  `rule_key` varchar(64) NOT NULL,
  `rule_version` int NULL,
  `query` varchar(500) NULL,
  `facts` json NULL,
  `conclusion` json NULL,
  `llm_conclusion` json NULL,
  `deviated` tinyint NOT NULL DEFAULT 0,
  audit + tenant_id,
  PRIMARY KEY(id), INDEX idx_tenant_time(tenant_id, create_time)
) ENGINE=InnoDB ... COMMENT='AI 规则命中留痕';
```
执行 + 验证。

**Step 3: DO/Mapper** — AiRuleDO(TenantBaseDO, 字段对齐 DDL); AiRuleHitDO(TenantBaseDO); Mapper: selectByKeyAndStatusIn/selectByKeyOrdered/selectPage(同 prompt)。

**Step 4: RuleResult** — `service/rule/RuleResult.java`: 通用结论 fact, `@Data @AllArgsConstructor public class RuleResult { private String code; private String text; }`(Drools insert 用; 需 public getter/setter/无参构造? Drools fact 需可访问——用 @Data + 有参构造即可)。

**Step 5: RuleCompiler** — `KieBase compile(String ruleKey, String drl)`: KieServices → KieFileSystem(kieModule 含 drl) → KieBuilder → 有错抛 IllegalArgumentException(带错误信息); 返回 KieBase。

**Step 6: RuleEngine** — `List<RuleResult> evaluate(String ruleKey, Long tenantId, Map<String,Object> facts)`: 解析启用/灰度版本(同 PromptCache 模式: 启用行 + 灰度行 tenant 命中)→ 按 (tenant,ruleKey,version) 缓存 KieBase(30s)→ KieSession(facts 作为 Map fact insert)→ fireAllRules → collect RuleResult; 失败 log.warn 返回空列表(忽略规则)。

**Step 7: AiRuleService+Impl** — create(试编译→同 key maxVersion+1)/update(停用行可改, 试编译)/enable/grayEnable(需另有全量启用行)/grayOff/delete/page/get/keyList/validate(给定 facts 试运行返回命中)。

**Step 8: RuleApi + DTO** — `RuleEvaluateReqDTO{ruleKey, tenantId, facts:Map<String,Object>}`; `RuleEvaluateRespDTO{matched:boolean, conclusions:List<RuleResultView{code,text}>}`; `RuleApi.evaluate(@RequestBody RuleEvaluateReqDTO) → CommonResult<RuleEvaluateRespDTO>`(POST PREFIX+"/evaluate")。RuleApiImpl 委托 RuleEngine + 落 ai_rule_hit(仅命中时)。

**Step 9: Controller /rule** — 权限 `rule:rule:*`: create/update/enable/gray-enable/gray-off/delete/page/get/key-list + validate(facts → 命中列表)。

**Step 10: 编译 + 提交** — mvn compile; git commit "feat(rule): Drools 规则引擎(ai_rule/编译/引擎/管理API/RPC/留痕)"。

**Step 2: EvidenceService 步骤 0.5** — 槽位检测短路之后、检索(assembler)之前:
```java
// 0.5 硬规则优先(命中直接给结论, 不走检索/LLM)
RuleShortCircuit.RuleConclusion rc = ruleShortCircuit.evaluate(query, Map.of("query", query));
if (rc != null) {
    judgement = buildJudgement(true, 1.0, null, 0, 0);
    EvidenceEvaluateRespVO resp = buildResp(traceId, query, judgement, List.of(), List.of(), null, history);
    resp.setAnswer(rc.text());
    resp.setElapsedMs(...);
    recorder.record(resp, List.of(), List.of());
    return resp;
}
```
