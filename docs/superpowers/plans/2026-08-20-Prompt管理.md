# Prompt 管理 M6-B 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** 12 处提示词常量改为 DB 版本化管理(model-server ai_prompt): 管理 API(版本/启用/租户灰度/回滚)、PromptApi RPC、消费方 PromptSupport(失败回退内置默认); 30s 内生效。

**Step 4: AiPromptService + Impl** — 方法:

**Step 5: PromptCache** — 进程内缓存:
```java
@Component
public class PromptCache {
    /** TTL 30s(改/灰度/回滚 ≤30s 生效) */
    private static final long TTL_MS = 30_000L;
    private record Entry(String enabledContent, String grayContent, List<Long> grayTenantIds, long expireAt) {}
    private final Map<String, Entry> cache = new ConcurrentHashMap<>();

    public Entry get(String key) { Entry e = cache.get(key); if (e != null && e.expireAt() > now()) return e; cache.remove(key); return null; }
    public void put(String key, Entry e) { cache.put(key, e); }
    public void evict(String key) { cache.remove(key); }
}
```

**Step 7: PromptApiImpl** — @RestController 实现:
```java
    public CommonResult<String> getPrompt(String key, Long tenantId) {
        Long t = tenantId != null ? tenantId : TenantContextHolder.getTenantId();
        PromptCache.Entry e = cache.get(key);
        if (e == null) {
            List<AiPromptDO> rows = mapper.selectByKeyAndStatusIn(key, List.of(1, 2));
            String enabled = null; String gray = null; List<Long> grayIds = List.of();
            for (AiPromptDO r : rows) {
                if (r.getStatus() == 1) { enabled = r.getContent(); }
                else if (r.getStatus() == 2) { gray = r.getContent(); grayIds = parseTenantIds(r.getGrayTenantIds()); }
            }
            e = new PromptCache.Entry(enabled, gray, grayIds, System.currentTimeMillis() + TTL_MS);
            cache.put(key, e);
        }
        if (e.grayContent() != null && e.grayTenantIds().contains(t)) return success(e.grayContent());
        return success(e.enabledContent()); // null 表示无配置
    }
```
(package `cn.iocoder.yudao.module.model.api`; 需要 TenantContextHolder 兜底取租户; parseTenantIds 解析 JSON 数组; 注意 Entry 是 PromptCache 内部 record —— PromptApiImpl 通过 cache.get 拿 Entry, 需要可访问(把 Entry 设为 public record 或提供 getter 方法)。

```java
@Component
public class PromptSupport {
    @Resource private PromptApi promptApi;
    /** 取提示词: DB 有则用, 无/异常回退内置默认 */
    public String get(String key, String defaultPrompt) {
        try {
            Long tenantId = SecurityFrameworkUtils.getLoginUser() == null ? null
                    : SecurityFrameworkUtils.getLoginUser().getTenantId();
            String p = promptApi.getPrompt(key, tenantId).getCheckedData();
            return StrUtil.isBlank(p) ? defaultPrompt : p;
        } catch (Exception e) {
            log.warn(...);
            return defaultPrompt;
        }
    }
}
```
(注意: 无登录态的 RPC 场景(如 EvalRunner 异步) tenantId 传 null, model 侧用 TenantContextHolder 兜底; 各模块依赖 model-api 已有)
