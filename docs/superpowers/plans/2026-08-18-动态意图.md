# 知识库级动态意图实施计划(7 任务)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** 意图按知识库配置(ai_intent 表 + 发布时 LLM 自动总结 + 手动管理);检索/评估用对应知识库意图集分类;问题意图超范围 → 转人工不硬答。

**Spec:** `docs/superpowers/specs/2026-08-18-动态意图-design.md`

---

## 环境前提
- knowledge-server(48084): 版本发布 publish 已存在(幂等);ModelApi 已登记;权限 knowledge:*
- retrieval-server(48086): QueryAnalysis 固定 6 枚举;SearchService 有 answerBlocked 短路;KnowledgeApi 已登记(RpcConfiguration)
- chat-server(48083): 转人工机制(transferReason)已就绪;evidence answerBlocked → answerable=false 已有
- evidence-server(48087): SufficiencyJudge 已有"检索阻断"路径

## 任务

### Task 1: DDL + DO/Mapper + IntentService CRUD + Controller
- DDL ai_intent(kb_id/name/description/source LLM_AUTO|MANUAL/status + 审计)
- AiIntentDO/AiIntentMapper(knowledge-server dal, TenantBaseDO + BaseMapperX)
- IntentService: listByKb(kbId, 仅启用可选)/create(MANUAL)/update/delete/listPage
- IntentController: GET /knowledge/intent/list?kbId= / POST create / PUT update / DELETE delete;权限 knowledge:intent:query/create/update/delete
- 菜单/权限入库(按钮 type=3, parent=知识库菜单 2915)
- 编译 + 启动验证

### Task 2: IntentSummarizer + 发布触发 + RPC
- IntentSummarizer(knowledge-server, @Component + ModelApi): 取该版本已发布 chunks content(≤20条×200字) → LLM 总结 JSON {intents:[{name,description}]} → 覆盖该 kb 的 LLM_AUTO 条目(保留 MANUAL)
- 触发: AiDocVersionService.publish 成功后异步执行(AsyncExecutor;失败 log.warn 保留旧意图, 不阻断)
- 手动 summarize: IntentController POST /knowledge/intent/summarize?kbId= → 同步执行返回新意图数
- RPC: KnowledgeApi 加 `getKbIntents(kbId) → List<IntentDTO>{name, description}`(仅启用);KnowledgeApiImpl 委托 IntentService
- 编译 + 启动验证(发布 → ai_intent 生成)

### Task 3: QueryAnalysis 动态意图
- QueryAnalysisService: analyze(query, history, List<IntentDTO> intents);prompt 动态注入意图列表 + OUT_OF_SCOPE 选项;intent=匹配名|OUT_OF_SCOPE
- 无意图配置 → intent 不分类(不判超范围, 兼容旧行为)
- SearchService: 从 KnowledgeApi.getKbIntents(kbIds 对应库)拉意图(多库取并集;kbIds 空=全部可见库的意图并集——经 getVisibleKbIds);传给 analyze
- 编译 + 启动验证(带意图 vs 不带)

### Task 4: 超范围短路
- SearchService: analysis.intent==OUT_OF_SCOPE → 不检索(跳过 BM25/向量)、answerBlocked=true、answerReason="问题超出知识库服务范围(意图未匹配), 已转人工"、results=[]
- evidence: retrieval answerBlocked → SufficiencyJudge 已走"检索阻断"answerable=false(验证传导)
- chat: evidence refusalReason 含"超出" → transferReason="超出知识库范围"(TransferHandler 映射扩展)
- 编译 + 启动验证("换手机推荐"→ OUT_OF_SCOPE → answerBlocked)

### Task 5: 前端意图管理
- api/ai/intent/index.ts(knowledge 模块意图接口)
- 知识库列表行操作加"意图管理" → 弹窗/抽屉: 意图列表(name/description/source Tag/status Switch)+ 新增/编辑/删除 + "重新总结"按钮(summarize → 刷新)
- 检索测试页: intent 展示动态名;OUT_OF_SCOPE → 红色徽标 + 拒绝卡片(复用 answerBlocked 卡片)
- typecheck + 提交

### Task 6: 端到端验证 IT-01~IT-06
- IT-01 发布后自动总结(ai_intent 生成 LLM_AUTO)
- IT-02 手动 CRUD + 重新总结保留 MANUAL
- IT-03 "碎屏能免费修吗" → 命中保修意图正常回答
- IT-04 "换手机有什么推荐" → OUT_OF_SCOPE 不硬答转人工
- IT-05 无配置库兼容(不误判)
- IT-06 检索页动态意图 + OUT_OF_SCOPE 展示
- 验证记录写入计划文档
