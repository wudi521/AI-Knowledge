# 模型网关 M6-A 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** model-server 落地生产级模型网关: 多模型注册(ai_model_config + scenario/priority)、按 (租户,类型,场景) 路由、瞬态重试+主备降级+熔断、全量计量(ai_model_call_log); 消费方零改动, yaml 默认兜底。

**Architecture:** ModelApiImpl 委托 ModelGateway 编排: ModelResolver(路由: 租户场景 → 默认 → yaml)→ ModelInvoker(OpenAI 兼容 HTTP)→ RetryPolicy(瞬态重试指数退避, 4xx 不重试)→ CircuitBreaker(单模型失败≥5 短路 30s 半开)→ FallbackRouter(主败切备)→ CallMeter(异步落 ai_model_call_log, TtlRunnable 传租户)。领域无关, 多场景验收(物流/HR, 不以售后为锚点)。

**Tech Stack:** Spring Cloud Feign / MyBatis-Plus(TenantBaseDO) / RestTemplate / TtlRunnable / qwen3-8b + bge-m3 + bge-reranker(现网模型)。

**Spec:** `docs/superpowers/specs/2026-08-20-模型网关-design.md`

- [ ] **Step 1: YamlModelDefaults** — 读取 `yudao.model.{chat,embedding,rerank}.{base-url,model}` 的只读配置(Environment), 提供 `resolve(type)` 返回虚拟 ModelTarget{baseUrl, modelName}。

- [ ] **Step 2: ModelCallResult** — record {status: SUCCESS/FAILED/DEGRADED, content/vectors/scores(按类型), promptChars, completionChars, promptTokens, completionTokens, elapsedMs, modelName, provider, modelId, attempt, errorMsg}。

- [ ] **Step 3: ModelResolver** — `List<AiModelConfigDO> resolveCandidates(String type, String scenario)`: tenant 过滤由 mapper 自动; 先查 (type, scenario) 启用行, 空则查 (type, '*') 启用行; 按 priority 升序; 均空返回空列表(gateway 回退 yaml)。

- [ ] **Step 4: ModelInvoker** — `ModelCallResult invoke(AiModelConfigDO cfg, InvokeRequest req)`: 按 type 组 OpenAI 兼容请求体(chat completions / embeddings / rerank, 镜像现有 ModelApiImpl 三个方法 + apiKey header Bearer 可选), 解析响应 + usage(有则取 prompt_tokens/completion_tokens), 抛 ModelInvokeException{retryable: 超时/5xx/网络错=true; 4xx/解析失败=false}。RestTemplate 读超时用配置(默认 300s, 对齐 LLM 链路)。

- [ ] **Step 5: RetryPolicy** — `attempts(retryable)` = retryable ? 2 : 1; 退避 200ms/400ms。

- [ ] **Step 6: CircuitBreaker** — 进程内 ConcurrentHashMap<modelId, State{failures, openedAt, halfOpenProbe}>; `tryAcquire(modelId)`(OPEN 且未过窗口 → false; HALF_OPEN 只放 1 个探测); `onSuccess/onFailure`(连续失败≥5 → OPEN 30s)。

- [ ] **Step 7: CallMeter** — 专用单线程守护 ExecutorService + TtlRunnable(与槽位总结同模式); `record(ModelCallResult r)`: 组装 AiModelCallLogDO insert; 失败 log.warn 不抛出。

- [ ] **Step 8: ModelGateway** — 编排:
```java
public String chat(ModelChatReqDTO req) // scenario=req.scenario, traceId=req.traceId
public List<List<Float>> embedding(List<String> texts, String scenario, String traceId)
public List<Float> rerank(ModelRerankReqDTO req, String scenario, String traceId)
```
内部 `invokeWithFallback(type, scenario, traceId, InvokeRequest, ModelCallResult default...)`:
```java
List<AiModelConfigDO> candidates = resolver.resolveCandidates(type, scenario);
boolean degraded = false;
for (AiModelConfigDO cfg : candidates) {
    if (!breaker.tryAcquire(cfg.getId())) { continue; }
    int attempts = retryPolicy.attempts(true);
    for (int a = 1; a <= attempts; a++) {
        long t0 = now; try {
            ModelCallResult r = invoker.invoke(cfg, req); r.setAttempt(a); r.setElapsed(now-t0);
            breaker.onSuccess(cfg.getId());
            meter.record(r.setStatus(degraded ? DEGRADED : SUCCESS));
            return r;
        } catch (ModelInvokeException e) {
            meter.record(failed(...attempt a...));
            if (!e.isRetryable() || a == attempts) { breaker.onFailure(cfg.getId()); break; }
            sleep(backoff(a));
        }
    }
    degraded = true; // 下一个候选
}
// 全候选失败 -> yaml 兜底(若 candidates 非空才需要; 空则直接 yaml)
```
yaml 兜底: 调 invoker 一次(带重试, retryable 2 次), 失败抛 ServiceException(INTERNAL_SERVER_ERROR, "模型调用失败: ...")。
**注意**: embedding/rerank 幂等可安全重试; chat 非幂等, 仅对"未收到响应"类瞬态错误重试(超时/连接错), 收到 5xx 也重试(服务端未处理), 文档注明语义。
