# 设计文档:规则引擎 M7-A(生产级, Drools)

> 日期:2026-08-21 · 状态:用户确认(DRL 存 DB 租户级版本化; 规则优先于 LLM; 非售后锚点)
> 前置:PRD《M7 Agent·流程·规则引擎》BR-011(硬规则优先, LLM 冲突以规则为准并记录偏差); M6 模型网关/Prompt 管理已交付(同模式复用)
> 定位:yudao-module-rule(48088) 落地 Drools 规则引擎。**领域无关**——规则内容/事实键全是数据, 无行业硬编码。

---

## 1. 目标与非功能需求

**目标**: DRL 规则存 DB(租户级, 版本化/启用/灰度/回滚), 运行期 KieBuilder 编译执行; evidence 管线规则优先: 命中硬规则 → 直接以规则结论作答(不走 LLM), 未命中 → 原 LLM 管线; 命中留痕。

**非功能需求**:
| 维度 | 要求 |
|---|---|
| 可用性 | 规则评估失败 → 忽略规则走原 LLM 管线(不阻断); 编译失败 → 管理端报错, 不影响已启用版本 |
| 时效 | 规则变更 ≤30s 生效(缓存 TTL) |
| 版本化 | 每 rule_key 多版本, 仅 1 启用 + 可选灰度(与 ai_prompt 同模式) |
| 多租户 | ai_rule 租户级(TenantBaseDO), 规则集互不可见; 命中留痕按租户 |
| 领域无关 | 事实=Map, 结论=通用 RuleResult, 键/值全数据驱动 |
| 安全 | DRL 是代码, 管理端权限(model 同级 rule:rule:*); 规则内容审计 |

## 2. 架构

```
管理端: /rule/* CRUD(保存时试编译) + enable/gray/validate 试运行
rule-server(48088)
  ├─ RuleCompiler: DRL → KieBase(保存时编译校验)
  ├─ RuleEngine: evaluate(ruleKey, tenantId, facts) → List<RuleResult>
  │     └─ KieBase 缓存(30s TTL, 启用/灰度变更失效)
  └─ RuleApiImpl.evaluate(RPC) ← evidence-server 调用
evidence-server
  ├─ RuleShortCircuit: 组装问题事实(意图/实体/槽位值) → RuleApi.evaluate
  └─ 命中 → answerable=true + answer=规则结论 + ai_rule_hit 留痕; 未命中 → 原管线
依赖: drools 8.x(drools-engine/kiesession/compiler)
```

## 3. 数据模型

### ai_rule(租户级 TenantBaseDO)
| 列 | 说明 |
|---|---|
| rule_key | varchar(64) 业务键(如 warranty-condition/delivery-condition) |
| name / description | 名称/说明 |
| drl_content | text DRL 规则文本 |
| version | int 同 key 自增 |
| status | 0停用/1启用全量/2灰度中(+gray_tenant_ids) |
| gray_tenant_ids | varchar(500) JSON 数组 |

### ai_rule_hit(留痕; TenantBaseDO)
tenant_id / rule_key / rule_version / query / facts(JSON) / conclusion(JSON) / llm_conclusion(JSON, 预留冲突对比) / deviated(tinyint) / create_time

## 4. 规则模型(领域无关约定)

- 事实: `Map<String,Object>`(调用方组装: query/意图/实体/槽位值/自定义键)
- DRL 约定: 规则条件用 `$f: Map()` + `$f["key"]`; 命中结论 `insert(new RuleResult("结论文本", "结论编码可选"))`; 引擎收集全部 RuleResult
- 示例(物流场景, 非售后):
```drl
rule "跨省配送时效"
when
  $f: Map($f["region"] == "跨省")
then
  insert(new RuleResult("跨省配送时效 3 天", "delivery-3d"));
end
```
- RuleResult: rule-server 提供的通用事实类(领域无关)

## 5. 接口

- `RuleApi.evaluate(RuleEvaluateReqDTO{ruleKey, tenantId, facts})` → CommonResult<RuleEvaluateRespDTO{matched, conclusions:[{code,text}]}>; 失败 → error(调用方忽略走原管线)
- admin(权限 rule:rule:*): POST /rule/create(试编译)/update/enable/gray-enable/gray-off/delete/page/get/key-list + POST /rule/validate{facts}(试运行看命中)

## 6. 降级与边界

| 场景 | 行为 |
|---|---|
| DRL 编译失败(保存时) | 管理端报错, 不入库 |
| 运行期 KieBase 构建失败 | log.warn, 忽略规则走原管线 |
| RuleApi RPC 失败/超时 | evidence 忽略规则走原管线 |
| 未配置规则 | 直接走原管线 |
| 命中多条规则 | 取全部 RuleResult(结论合并策略: 默认取第一条, 后续可配优先级) |
| 租户无规则 | 走原管线 |
